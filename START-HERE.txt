East-Gade — светлая версия сайта

Для запуска: npm install, скопируйте .env.example в .env, заполните настройки и выполните npm start.
Сайт и endpoint приёма заявок должны работать на сервере с Node.js; одной статической публикации HTML недостаточно.

Страница платежей: popolnenie-alipay-wechat.html
Постоянная светлая тема: assets/light.css
Стили, скрипты и изображения: assets/

Формы отправляют заявки через серверный endpoint /api/lead в Telegram-группу. Сервер отправляет сообщения к Telegram Bot API через SOCKS5h-прокси. Токен бота, chat ID и адрес прокси храните только в серверном .env или переменных окружения, никогда не добавляйте их в HTML/JavaScript.

Создайте бота через @BotFather, добавьте его в нужную группу с правом отправлять сообщения и задайте TELEGRAM_BOT_TOKEN и TELEGRAM_CHAT_ID. Для группы chat ID обычно начинается с -100. Укажите прокси как SOCKS5H_PROXY=socks5h://[логин:пароль@]хост:порт. Перезапустите приложение после изменения переменных.

Проверьте отправку с формы на сайте. При ошибке форма предложит отправить подготовленный текст менеджеру вручную. Для публикации сайт нужно развернуть на Node.js-хостинге или настроить reverse proxy к Node-приложению; обычный static hosting endpoint /api/lead не исполняет.
Курс и итоговую сумму подтверждает менеджер. Шрифты загружаются из интернета; без подключения используются системные шрифты.
